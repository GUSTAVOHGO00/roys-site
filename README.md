# Roy's Sandwich Shop

Site institucional da Roy's, desenvolvido em React, Vite e Motion.

## Desenvolvimento

```powershell
npm.cmd install
npm.cmd run dev
```

## Publicação

O push para a branch `main` executa o build e publica automaticamente no GitHub Pages.

Domínio de produção: [www.roys.com.br](https://www.roys.com.br)
